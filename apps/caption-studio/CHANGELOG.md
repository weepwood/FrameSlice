# 更新记录

## v0.4.0 — 编辑工作台 UI 与校对体验

- **视觉统一**：调整工作台留白、配色、卡片层次、按钮状态、视频区和右侧字幕列表；在宽屏中为列表设置独立滚动区，窄屏自动切换为单列。
- **工作流程提示**：在编辑区顶部显示媒体导入、语音识别、字幕校对、导出四个阶段，点击第四步可直接切换导出面板。
- **播放器精细校对**：增加 0.5×～2× 倍速和选中字幕循环播放；修正切换媒体后的倍速恢复。
- **字幕质量工具**：一键筛选有问题字幕、定位下一处问题、批量清理多余空白、谨慎修复可安全裁切的时间重叠，所有编辑进入撤销栈。
- **查找替换**：支持关键字搜索及忽略大小写的全文替换；文本替换按字面匹配，不把用户输入解释为正则表达式。
- **长字幕列表性能**：字幕列表每页最多渲染 100 条，提供翻页操作。播放跟随时自动切换到正在播放的字幕所在页。
- **导入体验**：支持拖入媒体/字幕/工程并显示全屏投放提示；添加快捷键帮助及 Ctrl/Cmd + K 搜索字幕。
- **稳定性修复**：媒体时长统计改为 `reduce`，避免超大字幕数组的 `Math.max(...array)` 参数数量上限。

**注意**：视频/音频原文件不会被上传到服务器。转录能力仍依赖浏览器支持 WebCodecs 解码对应音轨。大视频的处理性能需要在目标设备和实际编码组合上验证，浏览器内 MP4 烧录仍属于实验功能。
