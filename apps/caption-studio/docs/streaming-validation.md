# 大视频流式转录 · 验收清单

- 500MB、1GB、4GB MP4/AAC：点击开始识别，不再出现 350MB 拦截。
- 20s、30s、58s、65s 音频：检查最后字幕没有被裁掉，30s 边界前后没有重复字幕。
- WebM/Opus、MP3/WAV：确认按浏览器支持情况转换为 16kHz PCM。
- 无音轨/损坏文件：给出明确错误而非白屏；选择新媒体不会残留旧字幕 Worker 的回调。
- 波形按钮：不加载模型即可从大文件提取波形。
- 点击取消：Worker 被立即终止，后续不会继续追加字幕。
- Windows/macOS Chrome/Edge：各测试 WebGPU 与 CPU/WASM 模式。
- 真实长视频压力测试：持续内存、显存、应用程序占用、音画字幕同步校验。
- 仍需注意：FFmpeg.wasm 长视频硬字幕烧录未改造，建议长片先导出 SRT。
