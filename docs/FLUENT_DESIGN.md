# Fluent 2 工作台设计与播放器迁移

基线：V1.1.1（8fb541f），开发分支 feat/fluent-media，目标 V1.2.0。正式版本保持不变。

## 主题与公共控件

- Microsoft Fluent UI Web Components 3.2.4（MIT）与官方 Fluent Tokens 1.0.0-alpha.25（MIT），固定版本。后者为预发布依赖，仅用于生成静态主题文件，不在运行时调用。
- `node scripts/generate-fluent-theme.mjs` 从 webLightTheme / webDarkTheme 生成 `fluent-theme.css`，映射既有语义令牌；品牌前景与填充分离，主题、系统主题和嵌入 Shadow DOM 共享。勿手改生成文件。
- Vue WorkbenchButton（检查器和媒体资源入口等）迁移到 fluent-button，保留显式 button 角色；其余原生/Reka/Base UI 控件保持已验证交互，通过 fluent-controls.css 统一视觉。后续逐项审查可迁移控件、键盘与焦点、Shadow DOM、尺寸及精度，不盲目同时引入两套组件。
- 保留 react-resizable-panels 布局。后续按钮、选择器、输入、复选框、菜单、标签、进度和弹窗应逐项登记实际库归属与未迁移原因。

## 播放器

Media Chrome 4.19.5（MIT）提供真实媒体元素的播放、跳转、进度、音量、速度、画中画入口等控制，Vue 与 React 使用同一版本和 fluent-player.css。字幕无媒体状态保留虚拟时间轴；原字幕选中循环、字幕叠加及安全切点逻辑保留。嵌入编辑器使用小型 CaptionFullscreen 适配 ShadowRoot 的真实 fullscreenElement，避免 Media Chrome 误判退出状态；不支持标准 Fullscreen API 时禁用该入口。画中画能力取决于浏览器，DOM 字幕并不保证出现在画中画中。

## 验收及后续

83项单测、生产构建、两侧生产依赖安全审计零已知漏洞。真实 Edge 已验证两播放器的播放暂停、前后跳转、进度、音量状态、静音、倍速、全屏往返、字幕叠加、390px全屏按钮可见及四工作区统一布局，原媒体冒烟通过。16张本地视觉候选哈希验证；新增 browser-fluent-player.mjs 纳入正式CI。测试使用短合成视频，未验收实际画中画、带音轨声学输出、Firefox/WebKit新增播放器、数小时或12GB大文件。未批准新基线。
新增依赖增大包体积：主入口 gzip 31.88→95.00KB，字幕入口 197.70→约246.73KB。后续先拆分按需加载及避免重复播放器运行时，再集中迁移剩余控件和三浏览器回归。保留2%视觉门禁及V1.1.1发布资产。

## 第二批：共享播放器、控件与真实能力边界

- 根构建输出版本查询参数隔离的共享 ESM `dist/player/media-chrome.js`（包含使用到的控件及 MIT 许可），两个工作区在导入媒体时按需加载同一个 URL，字幕子项目移除重复依赖和嵌入主题 CSS。仅进入字幕工作台不触发请求；从字幕直接导入和从 Vue 切换到字幕均已验证。模块不可用时回退原生媒体控件，保留编辑能力，不承诺失败后无需刷新即可恢复。
- 在本地记录音量、静音及合法倍速，媒体切换后恢复，不记录媒体内容、不自动播放、不新增上传。选中字幕循环已真实验证越界回跳。Vue WorkbenchCheckbox 使用 Fluent 官方复选框，明确 aria-labelledby 及受控 checked；实际续作复选框回归通过。React 复选框、数值输入、选择器、菜单、弹窗、标签及进度仍复用成熟原语，统一 Fluent 外观、可访问边框和焦点、浮层表面。未完成所有官方控件迁移。
- 构建测量：主入口 gzip 95.00→52.67 KB（V1.1.1为31.88 KB）；字幕入口246.73→199.04 KB（V1.1.1为197.70 KB）；共享播放器独立gzip约40.36 KB，不含在两个入口内，只在需要时加载。不能将单个入口大小等同整个站点传输。
- 正式CI45643926901旧主题断言失败（旧背景#171b22、旧媒体条#20252e），现按官方Fluent深色#141414及#292929校验，真实Edge OPFS续作、跨标签锁、损坏拒绝及深色条带通过。一次画廊Home键回归未稳定复现，针对首尾按钮禁用后焦点丢失补充焦点回收，独立重跑原冒烟通过。
- 83项单测及构建、Edge真实播放器/字幕循环/持久化/单次共享请求/原生回退、PCM WAV及H264定位和四工作区布局通过；16张本地视觉候选采集及哈希验证。新增跨引擎PCM WAV播放、H264真实解码能力报告，纳入Firefox/WebKit正式CI，尚未取得对应结果。实际PiP及声学输出、长时和12GB仍未验收，不批准新基线。

## 第三批：播放器操作与官方进度条

- Media Chrome 自带倍速菜单替换循环点击，固定七档，显式注册菜单项；Vue、React及390px下直接选择均通过。共享焦点快捷键 Space/K、J/L、左右方向、M、上下方向及F；不拦截表单、菜单、编辑器、修饰键和输入法，禁用播放器内部重复热键。字幕工作区原有非播放器快捷键保留。实测播放、定位、静音、音量和字幕输入隔离通过，F入口实现但未独立键盘验收。
- 本机Edge158画中画实际进入/退出通过（源视频）；其他浏览器或系统可能不支持，不能保证DOM字幕出现在画中画。官方Vue Fluent进度条替换Reka进度展示，保留ARIA数值、7px任务和存储条、4px侧栏条，清理旧复选框与进度条CSS。React Base UI进度和其余复杂控件暂保留。
- 新增UI独立gzip预算门禁：根入口60,000B、App块115,000B、字幕入口215,000B、共享播放器55,000B。实际分别53,595/102,048/198,479/47,553B，四项通过。预算为本轮工程决策，非总传输体积；模型、Worker另行治理。倍速菜单使共享播放器比上一轮约增加7KB，仍按需加载。
- 上一提交CI45645582168主浏览器及Firefox/WebKit阶段通过，旧视觉门禁失败（预期改版待实际审阅），压力阶段尚运行。当前批次本机83单测、生产构建、真实倍速/快捷键/画中画/全屏/字幕循环/PCM WAV、历史任务与存储保护、16图候选哈希通过；正式新提交仍需三引擎、视觉和资源复验。保留2%视觉门禁、V1.1.1正式版本，不提前批准基线。
