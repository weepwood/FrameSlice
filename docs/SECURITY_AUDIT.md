# FrameSlice 稳定性与安全审计（2026-11-23）

本报告针对静态站点 `weepwood/FrameSlice` 中的 Vue UI、媒体读取、无损分割、定时抽帧、本地写入和 GitHub Pages 构建流程。审计以源代码审查、纯函数测试、小型 H.264/AAC MP4 集成测试、依赖公告扫描为基础，**不等同于独立安全渗透测试**。

## 主要风险、等级与处理结果

| 等级 | 风险 | 处理 |
| --- | --- | --- |
| 高（可用性） | 伪造时长、极短帧间隔可能导致生成极多截图时间点、CPU 与内存耗尽 | 截图间隔至少 0.1 秒；上限 10000 张；校验有限数值及起止区间；限制输出画面至 4000 万像素 |
| 中（稳定性） | 单个分割片段写入时逐包更新 Vue 视图，引发主线程频繁刷新 | 约 150 毫秒节流进度事件 |
| 中（完整性） | 音视频并发封装时其中一路出错，另一条写入链可能仍在运行 | 出错时取消 muxer，等待所有生产者结束后清理文件 |
| 中（文件管理） | 截图取消或写入失败可能留下残缺文件 | 中止 writable 后移除当前输出文件；每个任务独立目录 |
| 中（资源消耗） | 媒体索引异常、关键帧元信息过大 | 关键帧计数上限 250000；检查数据包长度和输入时长 |
| 中（文件安全） | 输入文件名包含路径分隔符、设备保留名称、过长名称 | Unicode 规范化与安全字符过滤；防目录穿越式名称，避免常见 Windows 设备文件名 |
| 中（供应链） | 缺乏依赖锁文件，发布时可能无意引入新版本间接依赖 | 提交 `package-lock.json`，CI 改为 `npm ci`，增加生产依赖高危漏洞扫描 |
| 低（纵深防御） | 静态页面没有附加 CSP 策略 | HTML 层添加 CSP，限制网络连接、脚本、对象、框架来源；保留本地 Blob 媒体访问 |

## 架构与隐私

- 所有媒体文件通过用户浏览器 `File` / `BlobSource` 读取，不包含将视频上传服务器的后端接口。
- 目录写入必须经过用户授权；当浏览器没有安全的目录写入功能时，大型视频分割会拒绝运行而不是加载完整视频再下载。
- 不保存用户的视频文件到仓库、云存储或服务端；任务状态目前只存在于当前页面内存。
- 外部 GitHub 链接使用 `noopener noreferrer`；用户文件名由 Vue 进行文本插值渲染，不作为 HTML 注入。

## 自动化验证

- `npm test`：规划器、边界条件、文件名校验、帧数上限和真实 MP4 重新封装、多片段输出及音视频轨道检查。
- `npm run build`：TypeScript 校验与 Vite 生产构建。
- `npm audit --omit=dev --audit-level=high`：阻止生产依赖出现被 npm 公告收录的高危或严重漏洞。
- `actions/deploy-pages`：只有测试和构建通过后才执行发布。

## 剩余风险和下一步

1. **浏览器解码器风险**：恶意构造的视频仍可能触发浏览器或底层媒体库自身的漏洞。CSP 不能保证对本地视频解码器攻击免疫，应保持浏览器及依赖更新。
2. **超大文件未做压力验证**：12GB、20GB、断续读写、磁盘空间不足、切换存储设备和异常掉电都需要真实设备测试。此版本不保证处理任何大小或格式的视频。
3. **非标准时间轴/编解码**：B 帧、VFR、edit list、AAC priming、部分 HEVC/AV1、跨码流配置变更可能导致时间戳、同步或封装问题。当前仅支持单视频轨、最多一条音轨，复杂源会拒绝处理。
4. **用户磁盘容量**：即使限制单次图片数量，10,000 张高分辨率图片仍可能耗尽磁盘空间；用户应指定容量充足的输出目录。
5. **主线程负载**：媒体预扫描仍在页面上下文中运行，长视频可能产生短时卡顿。后续可引入 Worker 执行解析和分割，并在 Worker 之间传递受限消息。
6. **HTTP 安全响应头**：GitHub Pages 的静态应用无法直接通过 HTML `<meta>` 设置 `frame-ancestors`、HSTS、X-Content-Type-Options 等服务端头。若需要强制抗嵌入或完整响应头策略，应改用支持配置安全响应头的静态托管服务。
7. **回归测试深度**：集成测试使用的是确定性小型 H.264/AAC 样本，不能代替各编码器、多片段、多小时长以及真实 12GB 文件的测试矩阵。
8. **依赖公告盲区**：`npm audit` 只能发现其漏洞数据库已知的问题，不是漏洞不存在的证明。

## 推荐后续优先级

优先：建立含 H.264/AAC、HEVC、VFR、B 帧、缺失音轨、损坏容器的测试素材集合；在本地浏览器对 12GB MP4 验证内存曲线、最终 MP4 完整性与音视频同步。

中期：将处理引擎迁移到 Web Worker，加入浏览器存储空间预检、片段校验报告、异常恢复和更完善的磁盘输出事务化策略。

远期：在测试覆盖后探索批量任务、关键帧预览、音轨导出、contact sheet 及码率/格式转换。**转码不应该被错误标记为无损处理。**
