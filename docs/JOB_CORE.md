# 统一任务核心

`src/core/workspace.ts` 提供与 Vue/React 无关的任务模型和调度。独立构建的两个模块通过 Symbol.for 共享一个页面内的运行时，限制媒体任务单并发，FIFO 等待；取消等待任务不会启动 Worker，运行中的任务必须等底层清理后释放资源。轻量操作仍直接执行。

- 文件身份按 File 对象区分，不能依据同名同大小自动认定为同一文件。
- 元信息缓存使用 WeakMap，不复制媒体字节。历史仅存 ID、名称、大小、时间、状态、最后完成的文件名等；侧栏可以清除已结束记录。
- IndexedDB 使用元数据快照，localStorage 保留兼容镜像；不保存 File 或目录句柄，也不保证跨标签页一致性。重载后标记 interrupted。分割与抽帧可用抽样指纹重新关联源文件、恢复参数并手动在新目录重试；非真正断点续作，不会覆盖旧文件。
- 输出检查点记录 Worker 已确认的文件；报告写入不属于 Worker 核心任务。未选目录的预览不是持久化成果。
- 当前保留三个原有一级导航，任务历史放在侧栏。全量任务中心、重新关联源文件、IndexedDB 检查点、重试和断点续作下一阶段建设。
- 真实 AI 转录及烧录仍需单独验证，不能以模拟测试或既有字幕导入冒烟测试替代。

## 可选完整续作
采用 IDB 独立 session 与输出记录，完整分块链式 SHA-256（不是标准文件 SHA-256）；仅受信任且完整指纹一致的输出可跳过，无法确认的文件拒绝覆盖。开启后额外读取源与输出；旧任务仍使用新目录重跑。权限需用户操作重新授权。
