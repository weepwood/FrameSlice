# 工作台使用指南

## 资源与布局
在媒体资源栏添加本地文件（会话内最多 50 个），点击切换。桌面宽屏可拖动资源栏与检查器边缘，或聚焦分隔条后用方向键调整；布局偏好本地保存。源文件本身不会持久化。

## 抽帧及时间轴
先分析视频获得完整关键帧索引。缩放/平移后点击生成缩略图，最多缓存六个视窗；切换源文件时回收。手动切割必须位于编码关键帧。抽帧可用拖选或秒数输入编辑区间。最清晰模式设置每窗口候选数 1–12 与最低拉普拉斯方差，场景模式设置 0–1 直方图距离阈值；并非语义场景识别或全帧最优。

## 续作和批处理
开启续作将额外完整读取源及输出，验证目录和内容；遇到不可信历史输出拒绝覆盖。任务中心可重新关联原文件。批量历史仅保存参数、文件元数据与状态，不保存原始文件；刷新后重新选择待处理文件并授权新目录，不自动继续或认定已完成。

## 发布与测试
见 REAL_BROWSER_TESTS.md。正式 Release 在主分支浏览器门禁及 Pages 部署成功后由工作流创建；没有 12GB 真实样本时必须明确标记未验收。

## 实验性媒体工具
轨道工作台新增 GOP 区间截取、同编码单视频、最多八音轨严格对齐合并和最多 8 条外部 MKV 软字幕。内嵌字幕轨复制尚不支持。截取起止点必须是精确 GOP 边界，末尾可为媒体结束。

批次恢复前可逐项检查目录授权；清除批次检查点只移除 IndexedDB 中的记录/句柄，不删除输出文件，但清理后不可再使用原检查点续作。

AAC 兼容合并默认关闭。开启仅允许完整且结束于零点的单个前置包被剔除，并报告数量与字节；可能产生接缝解码差异，不支持任意音轨时长差、重叠、填充或内嵌字幕无损复制。

内嵌字幕：切换轨道工作台至提取模式，选择可提取的 MKV UTF-8 字幕轨，输出 VTT。另支持 MKV ASS 与非分片 MP4 tx3g 文本提取；不支持图形字幕、复杂 MP4 分片或完整样式复制。

MKV S_TEXT/ASS 可独立提取 ASS，保留 CodecPrivate 样式及事件，字体附件不导出；复杂字幕变体拒绝处理。


## 专业字幕编辑
1. 导入 SRT/VTT 或打开 JSON 工程；替换前确认。工程只保存字幕与元数据，原视频需重新关联。
2. 多选编辑支持当前页、全部匹配、跨页逐条选择；时间偏移输入正数秒，按提前/延后决定方向。负时间或非法时长拒绝整批修改；编辑、整理和删除可撤销。
3. 问题筛选提供五种启发式规则；报告区分问题条数与受影响字幕数。可导出 JSON（不含正文，但含工程名及时间区间）。
4. 长工程每页100条字幕，可输入页码；手动翻页退出播放跟随，打开多选也暂停跟随。
5. 草稿读取失败时暂停保存，写失败可重试或导出备份；多标签页冲突先导出当前编辑再读取最新，不自动合并。关闭或清理站点数据前先备份。
6. 初次 AI 转录/实验性烧录可能联网获取模型与运行时，不上传原始媒体；真实推理性能未在每版重复验证。

## 输出、任务与浏览器限制
分割结果显示文件数和总字节数，每页50项，可从列表顶部翻页、按名称搜索；报告始终含全部输出。任务中心按类型、状态、媒体名称及时间排序，导出全部匹配记录。
无目录选择能力的浏览器不能启动无损分割或封装导出、不能新建断点续作；可使用媒体预检、分割规划和字幕编辑，抽帧最多30张单独下载，编码支持需实际验证。见 [浏览器能力边界](BROWSER_COMPATIBILITY.md)。

## V1.1 时间轴操作（开发分支）
- 媒体时间轴以播放位置为锚点缩放，Ctrl/Command+滚轮以指针为锚点，Shift+滚轮平移；适应完整时间轴可复位。吸附开关只影响定位及抽帧区间，手动切点始终由安全关键帧索引校验。分割点可拖动或用左右键选择相邻关键帧；抽帧区间可拖选或拖动两端手柄。
- 缩略图按需生成，可取消，单视窗最多13张，最多缓存6个完成视窗；切换媒体清空缓存。
- 字幕波形区域可拖动定位，左右键按0.1秒微调，Shift+左右键为1秒；边界拖动一次提交可撤销。多选编辑的时间比例校准以最早选中字幕起点为锚点，100%不变，负时间/不足80毫秒的字幕拒绝整批修改。

- 字幕校对工具栏：问题筛选、下一项、跟随及多选；「更多字幕操作」菜单含查找替换、整理文本、修复重叠。空工程隐藏无效操作，新增字幕与工程导入仍可用。

- 桌面端拖动预览与字幕检查器之间的分隔手柄调整宽度，聚焦手柄后可用方向键调整，布局比例本地保存；窄屏自动纵向排列。数值输入可直接键入精确值、使用加减按钮或方向键步进；输入步长不等于强制舍入。
