# MKV / MP4 轨道与软字幕处理

FrameSlice 的「视频分割」一级工作区中新增 **轨道提取与封装** 二级选项，原有「无损分割」保留。所有任务在浏览器 Worker 中运行，无上传和无后端，不依赖 FFmpeg.wasm 将整个 MKV 读入内存。

## 实际可用的功能

- **轨道扫描**：支持 MKV / MP4 / MOV / WebM 和部分音频输入，列出视频与音频轨道、编码、语言、名称和声道信息。
- **MKV 内嵌字幕提示**：从 EBML 元数据尝试识别字幕轨；无法复制的字幕显示为不可选。
- **逐轨提取**：每条选择的音视频轨道单独输出文件；AAC 导出 M4A、FLAC 导出 FLAC、MP3 导出 MP3、Opus/Vorbis 导出 Ogg，视频或其他兼容轨输出 MKV。
- **无损重新封装**：输出 MKV 或 MP4，强制压缩数据复制，兼容性不满足则拒绝输出而非自动转码、跳过勾选轨道。
- **软字幕封装**：添加 SRT/VTT，校验时间轴后写入 MKV 的 WebVTT 字幕轨。不会复制原 MKV 的内嵌字幕。
- **输出校验与报告**：重新解析视频与音频轨道、编码、时长、首尾包和新增字幕元数据；每项任务独立目录，生成 JSON 报告。失败或取消清理未完成输出。

## 使用步骤

1. 打开 https://weepwood.github.io/FrameSlice/ ，从左侧选择「视频分割」。
2. 切换到「轨道提取与封装」，选择 MKV / MP4；如果刚在视频分割工具中选择过文件，也可以复用。
3. 勾选需要提取或保留的轨道。
4. 选择「逐轨提取」或「重新封装」；重新封装可选 MKV、MP4，MKV 支持额外附加 SRT/VTT。
5. 阅读不支持的轨道及元数据风险，勾选明确确认。
6. 选择本地目录并运行。

## 限制与兼容边界

- **不是完整版 MKVToolNix。** Mediabunny 1.66.2 不能读取源容器中的字幕轨。额外 EBML 探针只分析文件前 8MiB，轨道表超出该范围时报告不确定。原 ASS/PGS、VobSub、字体附件、章节和未知轨道不支持原样提取与保留。
- **没有自动转码。** 音视频编码或时间戳与目标容器不兼容时任务会明确失败，所选轨道绝不会静默丢失。
- **新增软字幕优先 MKV WebVTT。** 不支持 MP4 mov_text 封装或 ASS 样式完整还原；播放兼容性也依赖播放器。
- **无损时间裁剪另行处理。** 现有按时间分割仍按关键帧对齐，不能等同任意位置的帧精确裁剪。
- **必须有文件夹写入能力。** 优先桌面 Chrome、Edge 的 HTTPS 页面；不支持时不会在内存里组装多 GB 数据。
- **完整性检测有边界。** 默认检验轨道结构、编码、时长和首尾压缩包，不等于全部帧解码验证。真实 12GB MKV、特殊音视频编码和音画同步仍需真实文件测试。
- **隐私**：轨道处理完全本地，不加载模型。现有 Whisper 转录等其他功能首次使用可能从外部下载运行资源。

## 测试

npm test 中新增真实 H.264/AAC 小样本回归，覆盖 MP4→MKV、轨道扫描、MKV 视频与音频提取、MKV→MP4、添加并校验 WebVTT 字幕轨、用户确认，以及 SRT/VTT 时间戳规则。

Chrome 端到端工作流还会运行 Worker、文件系统句柄和导出流程。
